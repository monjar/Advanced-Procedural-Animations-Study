# Motion capture

`cmu-02_01-walk.json` — one gait cycle of subject 02, trial 01 ("walk") from the CMU Graphics Lab Motion
Capture Database, via Bruce Hahne's MotionBuilder-friendly BVH conversion. Converted with
`tools/bvh-to-clip.mjs` (metres, 60 Hz, single loop-fixed cycle, foot contact labels).

> The data used in this project was obtained from mocap.cs.cmu.edu.
> The database was created with funding from NSF EIA-0196217.

CMU permits use in research and commercial projects; the data itself must not be resold.
